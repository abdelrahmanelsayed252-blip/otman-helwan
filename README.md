# عتمان في حلوان

لعبة قتال 3D في المتصفح على رصيف محطة مترو حلوان. آخر واحد واقف ياخد لقب "عتمان الحقيقي".

العب: https://abdelrahmanelsayed252-blip.github.io/otman-helwan/

- ضد الكمبيوتر، أو أونلاين مع صاحبك بكود أوضة.
- التحكم: WASD حركة · Space نط · J خفيفة · K تقيلة · L مسك · Shift دفاع. على الموبايل: جويستك وزراير.

3D character models made with [Meshy](https://www.meshy.ai) (CC BY 4.0). Built with three.js and Supabase.
